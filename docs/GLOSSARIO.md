# Glossário

Um termo, um sentido. Estes nomes valem para os textos da interface e para as docs.

- **Entra aqui:** cada termo do app, com uma definição curta e o arquivo de `spec/` que o usa.
- **Não entra aqui:** as regras em si, que ficam em `spec/`. Se uma definição daqui e uma regra divergirem, vale o spec, e o termo daqui é corrigido.

- **PIN:** código numérico de 4 a 8 dígitos usado para desbloquear o acesso. (`spec/autenticacao-e-webhook.md`)
- **Sessão:** período autenticado no navegador após inserção correta do PIN. (`spec/autenticacao-e-webhook.md`)
- **Webhook:** ponto de entrada para recebimento de sinais e automações externas autenticadas. (`spec/autenticacao-e-webhook.md`)
- **<Termo>:** <definição>. (`spec/<arquivo>.md`)
