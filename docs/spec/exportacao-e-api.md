## API de dados

- Outros apps (apps futuros, scripts, o Claude) leem os meus dados só pela API de dados, nunca
  direto do banco. *(4)*
- A API devolve transações (por período, conta, categoria e caixinha), contas e saldos, faturas,
  investimentos e o resumo do dia e do mês. *(4)*
- Pela API, outros apps podem gravar decisões: caixinha, categoria, nota e reembolso. *(4)*
